## How I work

My stack is the whole lifecycle, not a list of languages. AI does a lot of the typing; my job is to give it the right product, architecture and process — and to verify what it ships.

| Stage | What I bring |
| --- | --- |
| **Product** | PRDs, user stories and product logic before any code · roadmaps sliced into small specs · tickets with evidence, impact and direction |
| **UX** | Design systems and mockups before UI code · guides for operators and support |
| **Architecture** | System design, data flow and trust boundaries · ADRs, RFCs and threat models |
| **Build** | Spec-driven development — one agent writes, a fresh-context agent reviews, a human merges · automated tests from unit to end-to-end, gated in CI |
| **Ship** | CI/CD and infrastructure as code · signed releases · staged rollouts · multi-repo release trains |
| **Operate** | Logs, metrics, dashboards and alerts · post-release monitoring · incident reports |
| **Communicate** | Tickets, support-ready release notes and incident reports drafted by agents and owned by me · weekly recaps for non-engineers |

**Workflow.** Every project runs on [ai-workflow](https://github.com/rafagomes/ai-workflow): PRD → architecture → threat model → roadmap → specs → parallel agents in isolated worktrees → fresh-context review → human merge. On top of it I write my own skills and agents for tickets, releases, post-release monitoring and incident reports — the visibility work that usually gets skipped.

## What I know

- **Healthcare systems** — insurance eligibility, EHR/PMS integrations, patient-data privacy (HIPAA, LGPD).
- **Desktop apps** — Electron and .NET Windows services, code signing on Windows and macOS, remote over-the-air updates, encrypted local storage.
- **Control planes** — job brokers, agents that long-poll for work, fleet management, staged rollouts with canaries and circuit breakers.
- **Queues and background jobs** — retries, idempotency, dead-letter handling, schedulers.
- **Integrations and APIs** — REST and SOAP, partner APIs with scoped keys and audit logs, browser automation and scraping.
- **Observability** — structured logs with sensitive-data redaction, metrics, dashboards, alerting, log investigation.
- **Cloud and DevOps** — AWS (Lambda, ECS, RDS, DynamoDB, S3, CloudWatch), Terraform, Docker, GitHub Actions.
- **Mobile** — Android with Kotlin and Jetpack Compose, background work, signed releases.
- **AI engineering** — Claude Code agents, skills and hooks, MCP servers, spec-driven development.

## Side projects

- **[Hangar](https://github.com/thalissonbarbosas/hangar)** — a mouse-driven board that turns Jira tickets into Claude Code agent sessions: parallel runs in isolated git worktrees, risky shell commands gated for approval, output streamed live. `TypeScript` `Claude Agent SDK`
- **[Vagou](https://github.com/thalissonbarbosas/vagou-releases)** — Android app that watches health-plan schedules on the phone and alerts the moment a slot opens with the doctor you want. Background checks that survive Android's power limits, encrypted storage, signed and verified releases. `Kotlin` `Jetpack Compose`
- **[ticketmaster-watcher](https://github.com/thalissonbarbosas/ticketmaster-watcher)** · **[husky-watcher](https://github.com/thalissonbarbosas/husky-watcher)** — Manifest V3 Chrome extensions that watch a page and alert when something changes: sold-out tickets freeing up, an FX rate crossing your threshold. `JavaScript`
- **Private:** a multi-tenant Instagram analytics dashboard (Next.js, Supabase with row-level security), an Android setup wizard for retro emulation, and a manga-to-Kindle pipeline (Python CLI and Android app).
